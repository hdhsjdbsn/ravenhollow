# Ravenhollow — Beneath the Ashen Chapel

A gothic action RPG in the browser, packaged for SteamOS (Legion Go S, Steam Deck).

## Install on SteamOS (once)
1. Switch to Desktop Mode, open **Konsole** and run:

       curl -fsSL https://raw.githubusercontent.com/hdhsjdbsn/ravenhollow/main/get.sh | bash

2. Return to Gaming Mode. Ravenhollow is in your library under **Non-Steam**.

The game updates itself every time it starts (only changed files are downloaded) and plays offline.
